# LED Runner

Biến điện thoại thành bảng LED chạy chữ (marquee).

## Tính năng
- Chữ chạy với nhiều hiệu ứng: pixel, wave, glitch, shake, neon.
- Cuộn ngang hoặc dọc.
- Giữ màn hình luôn sáng khi trình chiếu.

## Stack & quyền
- Flutter (gần như 1 file).
- Không quyền đặc biệt.

## Build
```bat
build_apk.bat     :: hoặc: build_all.bat led_runner
```
